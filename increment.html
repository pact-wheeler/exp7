Help
HOW IT WORKS
Add folders of reference photos, tick the ones you want, build a
session out of sets, then press Start. Each pose shows a random
image for a fixed time. Draw the big shapes and gesture, not the
details. When time's up, the next image appears.

SETS (CLASS MODE)
A session is a list of sets that run in order, e.g.
  10 x 0:30  ->  5 x 1:00  ->  2 x 5:00
Start short and loose, then give yourself time on the longer ones.
Images are shuffled across all ticked folders with no repeats
until every image has been shown.

WHILE DRAWING
  Space  pause / resume        F  mirror the image
  ←      previous pose         G  grayscale (see values)
  →      skip / next pose      Esc  end session early

UNTIMED POSES
Type "untimed" as a set's time (or press [Untimed]) for slow study.
A stopwatch counts up instead of down, and the pose stays until you
press →. Handy after a few short warm-ups: 5 x 1:00, then untimed.

FOLDERS
Folders are remembered between visits. Chrome may ask you to allow
access again after a restart; click the folder (or Start) and accept.
Choose "Allow on every visit" to stop the prompts.
Set each folder's subject (Figures, Animals, Objects, Scenery) so the
recap shows the right review questions. See the Review tab (F3).

PRESETS
Build the sets you want, type a name in "Save as preset" and press
Save. It shows up under "Saved" in the Preset list. Pick a saved
preset and press Del to remove it.

After a session, click a recap thumbnail to see the reference large, with the questions for its subject beside it. Set each folder's subject in the folder list (Figures, Animals, Objects, Scenery or General).

How to review: hold your drawing next to the reference. Squint at both so the big shapes show and details drop away. Flip both: F here, and a mirror or a phone photo for your paper. Mistakes you'd stopped seeing jump out. Pick one question per session to focus on rather than all of them, and keep dated pages so you can compare across weeks.

Desktop Only

increment doesn't work on phones or tablets.

It needs a desktop or laptop with Chrome or Edge: it reads folders of reference photos from your computer, and it's driven by the keyboard while you draw.
